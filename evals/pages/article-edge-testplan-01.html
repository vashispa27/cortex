Checkout test plan: edge cases

Maintained by the payments QA group · updated 16 October 2026

This plan covers the checkout flow from cart review to payment confirmation. Each case lists the expected error code.

Cart cases

  • An edge case in this plan: a cart with 0 items and a coupon applied must show error CART-204.
  • Edge case: a quantity of 10,000 units must be rejected with error QTY-413.
  • A cart containing only a gift card skips the shipping step.

Browser matrix

Run the suite on Chrome 130, Safari 19 and Edge 130 before every release.

Payment cases

  • A card declined by the issuer returns the shopper to the payment step with error PAY-102.
  • A timeout from the payment provider retries once after three seconds and then shows error PAY-408.
  • A currency mismatch between the cart and the card is blocked before the authorization request.

Reporting

File defects in the payments board with the case number from this plan, the browser version and a screen recording. Link the build number so the fix can be verified against the same artifact.
